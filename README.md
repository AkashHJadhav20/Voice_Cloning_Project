# Voice Cloning Project

A Text-to-Speech system with voice cloning for 4 speakers (AB, AP, ME, DF) using XTTS-v2, optimized for GTX 1650.

## Features
- 🎤 4 Speakers: AB, AP, ME, DF
- 🚀 Optimized for GTX 1650 (4GB VRAM)
- 🌐 Web interface included
- 📝 Persistent voice selection
